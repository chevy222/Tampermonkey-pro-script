# Tampermonkey-enhance

一组给图片论坛用的油猴脚本。核心作用：**打开页面就把图全部加载好，不用一边滚一边等**，顺带清掉广告和无用元素。

适合不看代码、只想装完就用的人。**不需要会编程**，按下面的步骤做即可。

---

## 一、四个脚本分别是什么

| 脚本 | 用在哪个站 | 你会看到什么 |
|---|---|---|
| `2048缩略图.js` | `bbs.hdaksog.com` | 打开列表页/帖子页，图片立刻开始下载，不用滚动；右下角有加载进度；广告推荐块和右侧边栏消失 |
| `色花堂缩略图.js` | `bhagq.4yl7j.com` | 列表页原本只有文字，现在每帖下面多了缩略图；页面变宽屏单列；搜索页能勾选屏蔽不想看的栏目；帖子正文图开页即全部加载，右下角同样有进度提示 |
| `探花缩略图.js` | `sdy.685886.xyz` | 列表页每行居中显示一张预览大图；列表页和详情页的广告消失 |
| `sis001缩略图.js` | `www.sis001.com/forum/` 下的列表页 | 列表页每个帖子后面显示最多 3 张缩略图 |

## 二、安装

1. 给浏览器装扩展 [Tampermonkey](https://www.tampermonkey.net/)（油猴）；
2. 打开 Tampermonkey 面板 → **添加新脚本**；
3. 把对应 `.js` 文件的**全部内容**粘贴进去，按 `Ctrl + S` 保存；
4. 打开对应站点，刷新页面。

**怎么确认已经生效？**

- **2048**：右下角出现一个黑色小胶囊，写着 `缩略图已完成 12/47` 之类的字样（`已完成` 后面是「已经处理完的图片数 / 总图片数」，不是「正在加载的数量」）。列表页和帖子内容页都有。
- **色花堂**：列表页每个帖子标题下面出现了缩略图；右下角同样有进度胶囊（**列表页和帖子内容页都有**）。
- 探花 / sis001：列表里出现了图片。

看不到这些 → 见下面「问题一」。

> 从仓库里改了 `.js` 之后，**必须重新导入一次 Tampermonkey** 才会生效 —— 两边是各自独立的副本。
> 如果 Tampermonkey 没有提示更新，就在面板里**删掉旧脚本、重新添加**。

## 三、常见问题

### 问题一：完全没反应

按顺序排查：

1. Tampermonkey 扩展本身是不是开着、脚本前面的开关是不是绿色（已启用）；
2. 站点域名是不是变了 —— 脚本只对特定的域名生效。域名换了要改脚本开头的 `@match` 那一行（改成 `https://新域名/*`）；
3. 试着手动刷新一次页面；
4. 还是不行就把脚本删掉重新导入一遍。

### 问题二：图加载不出来，右下角进度条长时间不动

**这几乎都是图床（存放图片的服务器）那边的问题，不是脚本坏了。**

- 进度胶囊停在 `缩略图已完成 6/90` 很长时间，说明那批图片的服务器**接了请求但一直不回数据**。脚本在等它，等到超时（2048 等 20 秒、色花堂等 45 秒）才会把它标成失败；只要图已经能看见，就不会被算作失败。
- 进度条最终显示 `缩略图 40/47（7 张失败）`（橙色）= 这 7 张确实下载不下来，**不是脚本的问题**，换时间再试通常就好。
- 想立刻重新试一遍失败的图：**点一下变暗的图，或者点它右上角的 ↻**。
- 整个页面的图都很慢：说明那个图床本身慢或正在限速。脚本已经会自动放弃反复失败的图床（连续失败就整批跳过），不会一直卡着。

### 问题三：控制台里有一堆红色报错，是脚本的问题吗？

按 `F12` 打开控制台看到的**红色报错，绝大多数不是你装的脚本造成的**，是网站自己的代码在报错。常见的几条，看到就当作没看见：

| 报错内容 | 来源 |
|---|---|
| `[Violation] Permissions policy violation: unload is not allowed in this document.` | 站点自己的 `Compatibility.js` 用了浏览器已废弃的写法 |
| `PwFace.tabObj.getElementsByTagName is not a function` | 站点自己的 `post.js`（那个页面的容器没渲染出来） |
| `GET chrome-extension://invalid/ net::ERR_FAILED` | 浏览器扩展自身 |
| `net::ERR_BLOCKED_BY_ORB` / `403` / `ERR_NAME_NOT_RESOLVED` | 图片服务器拒绝了这批图片（图挂了 / 被墙 / 域名解析失败） |

**怎么判断是不是脚本的**：脚本自己的日志都带前缀 `[2048缩略图]` 或 `[色花堂缩略图]`。没有这个前缀 = 不是脚本。

### 问题四：想让脚本重新尝试之前失败的图

脚本会把"下载失败"的图记在浏览器里，短时间内不再去试（默认 5 分钟）。想让它立刻重试：

1. 在页面上按 `F12`；
2. 切到 **Application**（应用）标签 → 左侧 **Local Storage** → 点开当前站点；
3. 删掉 **`t2048BadImages`**（2048 站）或 **`sehuaBadImages`**（色花堂站）这一条；
4. 刷新页面。

> 这一条记录里同时包含"失败的图片"和"判定为不可用的图床"，删掉它就等于**全部赦免、重新试一遍**。

### 问题五：色花堂列表页的缩略图数量好像比帖子里的图少

这是故意设计的：移动版给出的图片地址**就是原始大图**（单张常有 1~4 MB），一页最多 30 个帖子，如果每帖都取 5 张，一页要下载上百 MB，页面会非常慢。

所以默认**每个帖子只取 2 张**。想改的话见下一节的 `MAX_THUMBS_PER_POST`。

## 四、想改设置

脚本的开关都在**文件最上面那一段**。在 Tampermonkey 面板里点脚本的「编辑」，改完 `Ctrl + S` 保存，刷新页面生效。

**按你想达到的效果来找：**

| 我的目的 | 改哪个 |
|---|---|
| 页面加载太慢 / 太费流量 | 色花堂：把 `MAX_THUMBS_PER_POST` 改成 `1` |
| 想让色花堂每帖显示更多图 | 色花堂：把 `MAX_THUMBS_PER_POST` 改成 `3`~`5`（流量会成倍增加） |
| 图床特别慢、想多等一会儿 | 把 `IMG_TOTAL_WAIT_MS` 调大（单位是毫秒，如 `60000` = 60 秒） |
| 不想让色花堂提前加载下一页 | 色花堂：把 `PREFETCH_NEXT_PAGE` 改成 `false` |
| 搜索页想默认隐藏别的栏目 | 色花堂：改 `BLOCK_FORUMS` 里的栏目名 |
| 还有广告没清掉 | 把广告元素的样式名加进 `REMOVE_SELECTORS` |
| 想看脚本的运行日志 | 把 `DEBUG` 改成 `true`，然后在 `F12` 控制台里看 |

**一般不需要动的参数**（说明用途，供参考）：

| 参数 | 含义 |
|---|---|
| `PER_HOST_IN_FLIGHT` | 同一个图片服务器「同时下载几张」。浏览器对单个域名一般只允许 6 条连接，设得更大也不会更快，反而会让请求堵在浏览器里空等，**不建议调大** |
| `MAX_IMG_IN_FLIGHT` | 全部图床加起来的同时下载总数（总闸） |
| `IMG_RETRY_TIMES` | 一张图失败后自动重试几次 |
| `HOST_FAIL_THRESHOLD` | 同一个图床连续失败几次就判定为不可用、剩下的图整批跳过 |
| `HOST_TIMEOUT_THRESHOLD` | 同一个图床连续超时几次也判定不可用 |

## 六、隐私

脚本**只在你自己浏览器里改页面显示**，不收集、不上传任何数据，也不会往外部服务器发东西。
唯一的例外是色花堂脚本为了拿缩略图，会用你已登录的身份去请求**该站自己**的移动版页面 —— 请求对象仍然是这个站点本身。
