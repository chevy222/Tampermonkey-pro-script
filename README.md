# Tampermonkey-enhance

针对图片论坛的一组油猴脚本。主要做两件事：**列表页自动加载全部缩略图**（不用滚动），以及**清掉广告和无用元素**。

---

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（油猴扩展）；
2. 把 `.js` 文件拖到 Tampermonkey 面板里，或者打开 TM → 添加新脚本 → 粘贴全文 → `Ctrl+S`；
3. 打开对应站点，脚本自动生效。

> 注意：改完仓库里的文件后，需要重新导入 TM 才会生效，两边是独立的副本。

## 2048缩略图.js

### 效果

- 打开帖子列表页，所有缩略图自动全部加载出来，不用往下滚
- 右下角显示加载进度（如 `缩略图加载中 12/47`），全部完成后自动消失
- 加载失败的图会自动重试，实在出不来的会压暗，点一下可以再试
- 自动去掉页面里的广告推荐块和右侧边栏
- 刷新页面后，之前加载失败的图不会重复浪费时间重试

### 常用参数（文件顶部可改）

| 参数 | 默认 | 说明 |
|---|---|---|
| `MAX_IMG_IN_FLIGHT` | 8 | 同时下载几张图。调大更快但可能被图床限速，建议 4~16 |
| `IMG_RETRY_TIMES` | 2 | 一张图失败后自动重试几次 |
| `IMG_TOTAL_WAIT_MS` | 20000 | 一张图最多等多久（毫秒），超时就算失败 |
| `REMOVE_SELECTORS` | 见代码 | 要删除的广告元素，按需增减 |

## 色花堂缩略图.js

### 效果

- 列表页本来只有文字标题，脚本自动在每个帖子下面加上缩略图（每帖最多 5 张）
- 打开页面就全部加载，不用滚动；右下角有进度提示
- 列表变成宽屏单列布局，只保留标题、日期和缩略图，更清爽
- 搜索页可以勾选隐藏某些栏目（如求片区、AI专区），只看你关心的内容
- 详情页自动加载全部正文图，不用滚动到底才慢慢出图；同时去掉广告
- 搜索提示"搜索繁忙"时自动等待并刷新
- 翻到下一页时，缩略图会提前准备好，点开就能看到

### 常用参数（文件顶部可改）

| 参数 | 默认 | 说明 |
|---|---|---|
| `MAX_IMG_IN_FLIGHT` | 16 | 同时下载几张缩略图。调大更快，0 表示不限制 |
| `MAX_THUMBS_PER_POST` | 5 | 每个帖子最多显示几张缩略图。改成 1 可以大幅减少流量 |
| `IMG_RETRY_TIMES` | 2 | 一张图失败后自动重试几次 |
| `IMG_TOTAL_WAIT_MS` | 45000 | 一张图最多等多久（毫秒）。图床第一次连接较慢，不建议改小 |
| `BLOCK_FORUMS` | 见代码 | 搜索页默认隐藏的栏目名称，按需增减 |
| `MAX_BUSY_RETRY` | 5 | "搜索繁忙"时自动刷新几次后停止 |
| `PREFETCH_NEXT_PAGE` | true | 是否提前加载下一页的缩略图。关掉可以省流量 |
| `DEBUG` | false | 改成 true 可以在控制台看调试日志 |

## 常见问题

**Q：脚本不生效？**
- 确认 Tampermonkey 是开启状态，脚本已启用
- 站点域名换了的话，需要把脚本里的 `@match` 改成新域名
- 刷新页面试试

**Q：图加载不出来，一直转圈？**
- 可能是图床暂时挂了，等一会儿刷新页面
- 右下角进度条显示"X 张失败"就是这些图确实加载不出来，点压暗的图可以手动重试
- 图慢的时候不要急，脚本会自动重试，进度条走完就稳定了

**Q：怎么改脚本里的参数？**
- 在 Tampermonkey 面板里点对应脚本的"编辑"，文件最上面就是参数区，改完 `Ctrl+S` 保存，刷新页面生效

**Q：会不会上传我的数据？**
- 不会。脚本只在你自己浏览器里改页面显示，不发送任何数据到外部服务器。
