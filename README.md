# Tampermonkey-enhance

一组给图片论坛用的油猴脚本。核心作用：**打开页面就把图全部加载好，不用一边滚一边等**，顺带清掉广告和无用元素。

适合不看代码、只想装完就用的人。

---

## 一、五个脚本分别是什么

| 脚本 | 用在哪个站 | 装完会怎样 |
|---|---|---|
| `色花堂.js` | `bhagq.4yl7j.com` | 列表页每帖下面自动出现缩略图（默认 4:3 横框，竖图加载完成后自动切 3:4 竖框，都居中裁切不拉伸；每行最多 5 张；右上角显示该帖图片总数）——图片按队列节奏加载（默认 4 张/秒），"新帖瀑布流"右边的「队列模式」可关掉改成一次性全出；页面宽屏单列、发帖日期搬到标题下；移动版没给出图的帖子会自动去详情页补图；详情页正文图开页即载、宽屏居中；检索页宽屏单列、缩略图 + 栏目过滤开关 + 按筛选结果自动翻页补齐（一页凑不满就继续往后抓原站，最多补 12 页，补的过程中显示进度）+ URL 里记着读到原站第几页（`page=N`），**刷新后从那页接着读、不用从头补** + 被拦截时先分类再重试（验证码/未登录直接提示不重试，限频按原站给的等待秒数等）；搜索快照过期时按钮会变成「重新搜索」（快照失效后同一个会话重试没用，只能用同关键词重搜）；右下角有加载进度胶囊（**翻页时重新计数，"继续补齐"时继续累加**） |
| `2048.js` | `bbs.hdaksog.com` | 图片打开页面立刻开始下载，不用滚动（列表页原生懒图和详情页占位图都立即加载）——同样按队列节奏加载，列表页「搜索」右边的「队列模式」可关掉改成一次性全出；广告推荐块、导航条、影片横幅、打赏卡消失，详情页右侧栏隐藏；右下角有加载进度胶囊 |
| `探花.js` | `sdy.685886.xyz` | 列表页每行居中显示一张预览大图，标题后跟分辨率徽章 + 「复制磁力」按钮（不用进详情页就能拿到 magnet）；广告消失 |
| `u9a9.js` | `u9a9.my`（备用 `u9a9.com` / `.org` / `.de` / `.win` / `.su`） | 列表页每行下面显示该帖详情页的预览图（最多 5 张，横图 4:3、竖图 3:4 居中裁切）；缩略图组右上角有数量角标，详情页超过 5 张时显示 `+剩余张数`；站内推广全清（页首页尾横幅、导航推广位、「推薦AI短劇」假告示条、详情页侧栏两整块、正文上方 JuicyAds），地址告示保留 |
| `sis001.js` | `www.sis001.com/forum/` 列表页 | 每个帖子后面显示缩略图 |

> `色花堂.js` 和 `2048.js` 是 2026-10 重写的 v4.0 版，和以前的「完整版 / 精简版」是**不同的脚本条目**。如果油猴里还装着旧版（名字带「缩略图」或「精简」的），建议删掉旧条目再装新的，避免同一个页面被处理两遍。

## 二、安装

1. 浏览器装扩展 [Tampermonkey](https://www.tampermonkey.net/)（油猴）；
2. 打开油猴面板 → **添加新脚本**；
3. 把对应 `.js` 文件的全部内容粘贴进去，按 `Ctrl + S` 保存；
4. 打开对应站点，刷新页面。

**怎么确认生效了？**

- **色花堂 / 2048**：右下角出现一个黑色小胶囊，格式为 `缩略图：成功 12 · 共 47`，有等待或失败时才会追加对应数字（如 `成功 40 · 失败 7 · 共 47`）；全部结束后约 2 秒自动淡出，有失败时显示橙色。
  - 色花堂检索页里：点「下一页」胶囊会**清零重算**（只统计当前页的图），点「继续补齐」则**继续累加**到同一笔账上；上一页迟到的图片回调会被丢弃，不会把数字算乱
  - **成功** = 已显示出来的图
  - **失败** = 明确不可达（404、连接被拒等）
  - **等待** = 超过 10 秒还没响应、仍在等的图。它**不会**被自动判成失败——胶囊会一直挂着显示"等待 N"，直到图真正落地，或者你刷新页面。所以看到"等待"不消失，说明那个图床确实没在返回数据，刷新通常能解决
- **探花 / sis001**：图片直接出现，不用滚动。
- **u9a9**：每个帖子下面出现缩略图，**不用滚动就会陆续加载**（不是原生懒加载，全量进队列后按节奏下载，每秒 10 张、同时在途最多 10 张）。
  - u9a9 的角标：详情页不足 5 张时显示总数，超过 5 张时显示 `+剩余张数`（例如 `+26` 表示另有 26 张没搬过来）
  - u9a9 的去广告：列表页两条 alert 只删第二条（「推薦AI短劇」那条，里面全是推广链接）；第一条「地址发發页 / 永久域名」是站点公告，**故意保留**。详情页删导航推广位、首尾横幅、两整块侧栏文字广告、正文上方 JuicyAds 广告条，正文图不受影响
  - 表格最右边那列「AD」（每行一个「視頻聊天」外链）**没有动**，因为删列会改变表格结构

> 改了 `.js` 文件之后，必须回油猴面板里重新粘贴保存才会生效。如果没提示更新，就删掉旧脚本重新添加。

## 三、常见问题

### 完全没反应

1. 油猴扩展是不是开着、脚本前面的开关是不是绿色；
2. 站点域名是不是变了 —— 脚本只对特定域名生效，域名换了要改脚本开头的 `@match` 那一行；
3. 刷新一次页面；
4. 还不行就删掉脚本重新导入。

### 图加载得慢 / 进度胶囊停住不动

**这几乎都是图床（存图片的服务器）那边的问题，不是脚本坏了。**

- 脚本默认按节奏排队加载图片，图床限速的时候胶囊会停在某个数字上等，不是脚本坏了。
- 胶囊最后显示 `缩略图：成功 40 · 失败 7 · 共 47`（橙色）= 这 7 张确实下不下来，等一会儿刷新，或者换个时间通常就好。
- 胶囊一直显示 `等待 N` 不消失 = 那 N 张的图床连上了但一直不返回数据。脚本不会把它们误判成失败，刷新页面重新来通常就好。
- 整页都慢 = 那个图床本身在限速。刷新页面会重新开始，不需要改任何设置。

### 控制台有红色报错

按 `F12` 看到的红色报错，绝大多数是网站自己的代码在报错，不是脚本的。新版脚本不打任何日志。

### 色花堂列表页太费流量

移动版拿到的图片地址就是原图（单张 1~4 MB）。脚本拿到几张就显示几张。如果嫌费流量，可以在色花堂脚本里找到 `createThumbWrap` 函数，给 `urls` 加个 `.slice(0, 1)`，每帖只留 1 张。

## 四、想改设置

脚本的开关都在**文件最上面那一段**。在油猴面板里点「编辑」，改完 `Ctrl + S` 保存，刷新页面生效。

| 我的目的 | 改哪里 |
|---|---|
| 搜索页想隐藏别的栏目 | 色花堂脚本里改 `BLOCK_FORUMS` 里的栏目名 |
| 还有广告没清掉 | 把广告元素的样式名加进 `REMOVE_SELECTORS`（2048 脚本） |
| 图片想一次性全出、不要排队 | 页面上的「队列模式」开关取消勾选（色花堂在"新帖瀑布流"右边，2048 在"搜索"右边；状态会自动记住） |
| 色花堂图片出得太慢 | 色花堂脚本里调 `IMG_START_PER_SEC`（每秒最多开始加载几张，默认 4）、`IMG_INFLIGHT_MAX`（同时最多几张在途，默认 6）、`IMG_TOKEN_CAP`（开页先放几张，默认 6）；2048 脚本有同名参数 |
| u9a9 想改每帖搬几张 / 加载快慢 | `u9a9.js` 里的 `CFG.maxThumbs`（每帖最多几张，默认 5）、`CFG.imgStartPerSec`（每秒最多几张开始下载，默认 10）、`CFG.imgInflightMax`（同时在途上限，默认 10）、`CFG.imgTokenCap`（开页先放几张，默认 10）。调小这几个值出图更慢但更不容易被图床限流 |
| u9a9 想去掉/保留广告 | `u9a9.js` 里的 `CFG.removeAds`，默认 `true`；改 `false` 则站点推广原样显示 |

其他参数（繁忙重试次数、胶囊淡出延迟等）一般不需要动。

## 六、隐私

脚本**只在你自己浏览器里改页面显示**，不收集、不上传任何数据。唯一例外是色花堂脚本为了拿缩略图，会用你已登录的身份去请求该站自己的移动版页面 —— 请求对象仍然是这个站点本身。
